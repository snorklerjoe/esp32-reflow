    GPIO pins
    Which pins can I use?

    The MAX6675s are read with software SPI, so the bus can go on any general-purpose GPIO. The dropdowns only offer pins that are safe on an ESP-WROOM-32:

    • 6–11: never usable. They're wired to the onboard flash.
    • 0, 2, 5, 12, 15: strapping pins, which can stop the board from booting. Pulling 12 high selects 1.8 V flash.
    • 1, 3: USB serial.
    • 34–39: input only. These are fine for SO but can't drive SCK, CS or the SSR.

    Changing pins stops any active run and takes effect immediately.

    PID gains
    Control & safety

    The SSR window is the time-proportioning period: the heater is on for duty% of each window. Max temp is a hard cutoff checked on both thermocouples in every mode. The door margin sets how far above a falling setpoint the oven must be before the app says to open the door.
